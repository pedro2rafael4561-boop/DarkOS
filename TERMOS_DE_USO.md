# Termos de Uso do DarkOS

**Última atualização:** Outubro de 2026

Bem-vindo ao **DarkOS**, o ambiente de desenvolvimento integrado (IDE) com inteligência artificial avançada e privacidade por design.

Ao baixar, instalar, compilar ou utilizar o DarkOS, você concorda com estes Termos de Uso. Caso não concorde, interrompa imediatamente o uso do software.

O DarkOS é distribuído sob a licença de código aberto MIT (com partes derivadas do Code-OSS / VSCode da Microsoft Corporation e Void). Você tem o direito de usar, copiar, modificar, mesclar, publicar, distribuir e executar o software, desde que preservadas as notas de direitos autorais originais.

### 2. Privacidade e Processamento de IA
- **IA Local Prioritária**: O DarkOS foi projetado para operar com modelos locais (como Ollama / Llama / DeepSeek / Mistral) executados diretamente na memória do seu computador. Nessas condições, **nenhum trecho de código, prompt ou arquivo de projeto é transmitido a servidores externos**.
- **Provedores de Nuvem Opcionais**: Caso você opte conscientemente por configurar chaves de API para provedores externos (ex: Anthropic, OpenAI, Google Gemini, OpenRouter), você reconhece e concorda que as requisições serão enviadas para os respectivos serviços de acordo com as políticas de privacidade de cada provedor terceiro.

### 4. Linha do Tempo e Checkpoints de Emergência
O DarkOS fornece mecanismos integrados de Linha do Tempo, Checkpoints e Botão SOS para minimizar riscos de perdas de arquivos acidentais. No entanto, é dever do usuário manter backups regulares e utilizar sistemas de controle de versão distribuídos (como Git).
